# OpenCS branding

STLC++ and the OpenCS exercise extension share the OpenCS icon family.
`media/opencs-icon.png` is the 256 × 256 PNG used by `package.json` for the
VS Code/Open VSX listing and by the README. The extension keeps its STLC++ name,
identifier and language contributions.

The image is copied unchanged from Kimia's
[OpenCS brand package](https://github.com/aalto-opencs/opencs-platform/pull/960):
`opencs-ui/public/brand/plugin/vscode/vscode-icon-256.png` at commit
`dd9733b09239acfc1d16b8ff28f5351f042364ba`. The shared collection is maintained in
the platform repo's top-level `brand/` directory.

Keep only this selected export here. Alternate sizes and editable originals
belong in the shared collection; builds do not download that private repo.
The Marketplace banner uses the brand's dark background, `#0B0B0C`.
